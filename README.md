# 双人绳索协作原型

一个基于浏览器的本地原型，按你的规则实现了：

- 双角色单机双控：`A/D` 控制角色 A，`←/→` 控制角色 B
- 只能左右移动，不能跳跃
- 绳子最大长度与最小间距约束
- 三类障碍：掉落障碍、地面钉刺、岩浆坑 + 浮动平台
- 双人都到终点才算胜利，任意一人死亡则失败
- 四段式关卡节奏，从教学到混合挑战

## 运行方式

直接双击打开 `index.html` 即可开始。

如果浏览器限制了本地脚本，也可以在这个目录下用任意静态服务器打开。

## 当前实现说明

- 绳子超长时，前进角色会被限制，无法无限拉开距离
- 两人不能完全重叠，会保持最小间距
- 钉刺有 `warning -> active -> cooldown` 的循环
- 岩浆坑需要等平台移动到脚下才能通过，平台会带着角色横向移动

## 后续可扩展

- 加入角色生命值与受伤反馈，而不是直接死亡
- 给掉落障碍和钉刺做更强的音效/震屏/粒子反馈
- 增加更复杂的平台路径、可变绳长、按钮机关与关卡编辑数据
